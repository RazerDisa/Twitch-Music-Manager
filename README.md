# Twitch Music Manager v1.1 — MVP

1. Загрузите index.html и app.js в отдельный репозиторий GitHub, включите Pages.
2. Откройте страницу по HTTPS. Зарегистрируйте приложение на https://dev.twitch.tv/console/apps. Укажите точный Redirect URL, показанный в панели. Если доступен выбор типа клиента, используйте публичный клиент для implicit flow. Не публикуйте секреты.
3. Введите Client ID, авторизуйтесь как владелец канала (Affiliate/Partner для баллов), создайте награду и подключите заказы. Для начала воспроизведения нажмите «Играть». Spotify и текстовые заявки требуют ручного выбора разрешённой версии.
4. OBS: добавьте страницу как пользовательскую браузерную панель (если доступна). Если авторизация или звук в панели не работают, откройте страницу в отдельном браузере и захватывайте его звук через Application Audio Capture или системный звук. Не добавляйте страницу как видимый источник сцены. Проверьте микшер и отсутствие двойного захвата.
5. Не открывайте несколько экземпляров панели одновременно. Токен хранится в sessionStorage, очередь и настройки — localStorage. После закрытия панели приём заказов прекращается; пропущенные заказы нужно обработать в Twitch вручную. Награда создаётся приложением; отклонение возвращает баллы, завершение/пропуск подтверждает заказ. Цена применяется при создании награды. Для изменения существующей награды введите новую стоимость и нажмите «Применить стоимость в Twitch». Изменение требует авторизации владельца и награды, созданной этим приложением.

Ограничения MVP: нет поиска через API Spotify/YouTube, проверки длительности, фонового плейлиста и восстановления пропущенных событий. YouTube может запрещать встраивание отдельных видео; Spotify не воспроизводится. Используйте только музыку с правами на трансляцию и соблюдайте условия платформ. Синтаксис JS проверен, реальная OAuth/EventSub и OBS интеграция не тестировались. GitHub Pages не является сервером обработки событий: панель должна быть открыта.
